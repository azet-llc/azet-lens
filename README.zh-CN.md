<h1 align="center">Mwoyeo</h1>
<p align="center"><a href="README.md">한국어</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <b>简体中文</b></p>
<p align="center"><b>任何屏幕，都能在文字原处用你的语言阅读。</b><br>
把透镜放在聊天、信息流或游戏上，原文消失，译文就写在原来的位置。</p>

<p align="center">
  <code>brew install midagedev/tap/mwoyeo</code><br>
  <sub>macOS 27 · Apple 芯片 · 全部在设备上处理 · <a href="https://github.com/midagedev/mwoyeo/releases/latest">v1.0.2</a></sub>
</p>

<p align="center"><img src="docs/media/hero.gif" width="640" alt="日语聊天上的透镜：新消息被就地改写为韩语；拖动透镜并调整大小，聊天在其下方滚动，按 ⌃⌥O 切换回原文。"></p>

Mwoyeo 读取透镜下方的文字，**将其从画面中擦除**，再以相同的位置、大小和颜色写上译文。它不是弹窗，也不是字幕条：屏幕直接以你的语言呈现，新消息到来、页面滚动时也会持续翻译。所有处理都在你的 Mac 上完成，屏幕上的任何内容都不会被发送出去。

## 安装

```bash
brew install midagedev/tap/mwoyeo
```

也可以从 [Releases](https://github.com/midagedev/mwoyeo/releases/latest) 下载磁盘映像，将 Mwoyeo 拖到“应用程序”文件夹。App 已签名并经过公证。

Mwoyeo 每天会向 GitHub 检查一次新版本，有新版本时会在菜单中提示。使用 `brew upgrade mwoyeo` 更新，或下载新的磁盘映像。在“设置 › 关于”中可以检查更新、关闭自动检查，并打开发布说明和问题跟踪页面。

### 系统要求

| | |
|---|---|
| **macOS** | 27.0 或更高版本 |
| **Mac** | 任何能运行 macOS 27 的 Mac：Apple 芯片（M1 或更新机型）或 MacBook Neo。不提供 Intel 版本。 |
| **权限** | 仅需“屏幕录制”：不需要辅助功能，也不监听键盘 |
| **网络** | 翻译无需联网。唯一的网络请求是每天一次的更新检查，可以关闭。 |
| **磁盘** | App 本身约 20 MB。语言包（以及 Apple Intelligence 模型，最多 8–14 GB）由 macOS 下载和存储。 |
| **显示器** | 数量不限，透镜可以放在任何显示器上 |

**哪些部分在设备上运行，各需要什么。** 所有处理都在你的 Mac 上完成，区别只在于用哪个引擎。

| 部分 | 需要 |
|---|---|
| 读取文字（Vision）、擦除文字（Core ML） | 无额外要求：所有能运行 macOS 27 的 Mac |
| 用**语言包**翻译（最快，可离线） | 对应语言组合的语言包，在 Mwoyeo 的“设置 › 翻译”或“系统设置 › 通用 › 语言与地区 › 翻译语言”中下载一次即可 |
| **不使用语言包**翻译、*高保真*引擎和*术语表优先* | 在“系统设置 › Apple 智能与 Siri”中开启 **Apple Intelligence** |

所有能运行 macOS 27 的 Mac 都支持 Apple Intelligence，但还有两个条件：Mac 的语言和 Siri 的语言必须是同一种受支持的语言，且在中国大陆不可用。在 Mwoyeo 支持的语言中，Apple Intelligence 支持英语、韩语、日语、中文、法语、德语、西班牙语、意大利语、葡萄牙语和越南语，但不支持俄语、乌克兰语和泰语：这三种语言只能用语言包翻译。没有 Apple Intelligence 时，Mwoyeo 全部使用语言包翻译。

**语言。** 支持英语、韩语、日语、中文（简体和繁体）、法语、德语、西班牙语、意大利语、葡萄牙语（巴西）、俄语、乌克兰语、越南语和泰语之间的互译，只要 macOS 有对应方向的翻译模型即可。*自动*会逐行检测源语言。App 界面本身提供英语、韩语、日语、中文（简体和繁体）、法语、德语、西班牙语、意大利语、葡萄牙语（巴西）、俄语和乌克兰语版本。

## 快速上手

1. **打开 Mwoyeo。** 它位于菜单栏（取景器图标），欢迎窗口会引导你完成后续步骤。
2. **允许屏幕录制。** 点按**允许**，然后在“系统设置 › 隐私与安全性 › 录屏与系统录音”中打开 Mwoyeo。如果之后透镜仍然是空的，请退出并重新打开 Mwoyeo。
3. **选择语言。** *翻译自*可以保持**自动**；*翻译为*默认是你的 Mac 的语言。
4. **获取语言包**（推荐）。在 Mwoyeo 的“设置 › 翻译”中，点按语言组合旁的**下载**。有语言包时，翻译几乎即时完成，且可离线使用。没有语言包时改由 Apple Intelligence 翻译，无需下载，但每行约需 0.5 秒。
5. **按下 ⌃⌥L 并拖出一个框**，框住想读的文字，例如 Discord 频道的消息列表或 Reddit 帖子。也可以直接点按，透镜会放在点按的位置。操作时按住 ⌥，透镜就会固定到屏幕而不是窗口（见下文）。

## 使用透镜

- **移动**：拖动透镜发光的边缘或顶部的名称标签。译文始终贴合下方的文字，只显示透镜内部的部分。
- **调整大小**：拖动右下角。
- **关闭**：点按名称标签上的 ✕（将指针悬停在透镜上即可看到）。
- **照常滚动和聊天。** 透镜内部可以点按穿透，下方的页面照常工作。新消息一到就会被翻译，滚动时译文也会随之移动。
- **窗口透镜或屏幕透镜。** 放在窗口上的透镜是*窗口透镜*（名称标签上显示 🪟）：它随窗口移动，窗口最小化或被遮挡时会隐藏。*屏幕透镜*（📌）停留在你放置的位置，无论下方是哪个 App，都会翻译其中的内容：适合字幕行，或经常在下方切换 App 的位置。点按名称标签上的图标即可切换。
- **透镜宜小。** 只框住要读的部分（聊天区域，而不是整个浏览器），翻译更快，也更省电。可以同时放置多个透镜。

菜单栏图标会列出你的透镜：可以分别开启或关闭、移除，或添加新的透镜。菜单中还有**显示原文**、**暂停**和设置。

### 快捷键

这些快捷键在任何 App 中都有效。可在“设置 › 快捷键”中更改或移除：点按快捷键，然后按下新的按键组合。两个 App 使用同一组按键时，macOS 无法告知 App，因此如果某个快捷键在其他地方也有作用，请录制另一个。默认快捷键避开了 Rectangle、Magnet 等窗口管理工具。

| | |
|---|---|
| ⌃⌥L | 添加透镜（拖出区域，或点按放置；按住 ⌥ 可固定到屏幕） |
| ⌃⌥O | 显示原文 / 译文 |
| 无 | 全部暂停、重新翻译（在菜单中；如有需要，可在设置中为其指定按键） |

## 设置

| 标签页 | 可更改的内容 |
|---|---|
| 通用 | 语言 · **显示方式**：*自适应*（默认：画面移动时显示普通色块，静止后无缝重写）、*快速*（始终显示色块，最省电）或*无缝*（始终重写）· 屏幕检查频率（4、8 或 15 fps）· 登录时打开 |
| 翻译 | **引擎**：*自动*（已安装语言包时使用语言包，否则使用 Apple Intelligence）、*高保真*（始终使用 Apple Intelligence）或*术语表优先* · 语言包 · **翻译记忆**：保留多少条译文以供复用（1,000、5,000 或 20,000 条；仅保存在内存中，退出 Mwoyeo 时清除）· **术语表**：专有名词，每行一条 `original = translation` |
| 外观 | **透镜样式**：*光晕*、*柔和*（仅在读取时发光）或*极简*（一条淡淡的线；悬停时显示名称标签）· 字体（默认、圆体、衬线）· 色块不透明度 · 用 AI 擦除带纹理的背景（照片和插画） |

## 技巧与故障排除

- **一直显示“正在翻译…”？** 通常是缺少语言包，请在“设置 › 翻译”中下载。安装后的第一个透镜也会稍慢，因为 macOS 需要先加载一次文字识别模型。
- **名称翻译不对**（角色、地名、用户名）？把它们加入术语表，并选择*术语表优先*。
- **更新后什么都不显示？** macOS 有时会再次请求屏幕录制权限。请在“系统设置”中检查，然后重新打开 Mwoyeo。
- **想对照原文？** 按 ⌃⌥O 查看原文，再按一次即可返回。
- **隐私。** Mwoyeo 只读取透镜下方的内容，绝不存储或发送，截取画面时也会排除自身的叠加层。它唯一会向互联网查询的是 GitHub 上的最新版本号，每天一次，可在“设置 › 关于”中关闭。

## 技术细节

每个环节都使用 Apple 的设备端框架：

| 环节 | 技术 |
|---|---|
| 捕捉 | ScreenCaptureKit — 每个透镜一个流，排除 Mwoyeo 自身的叠加层，仅在像素变化时输出帧 |
| 文字识别 | Vision `RecognizeDocumentsRequest`（段落）和 `RecognizeTextRequest`（行、感兴趣区域） |
| 翻译 | Translation 框架 — 低延迟语言包，没有语言包时使用高保真的 Apple Intelligence 模型 |
| 遵循术语表的翻译 | Foundation Models（设备端语言模型），可选 |
| 擦除 | 纹理背景使用 GPU 上的 Core ML MI-GAN 图像修复，纯色背景使用快速扩散填充 |
| 界面 | SwiftUI 与 Liquid Glass、菜单栏附加项、全局快捷键，支持 12 种语言 |

### 工作原理

```
ScreenCaptureKit ──► change map (16 px tiles) ──► scroll? shift blocks, read only the new strip
      │                       │
      │                       └─► changed rows ──► Vision (ROI) ──► erase ──► translate (lens first) ──► overlay
      │
      └─► still for 0.5 s ──► whole-frame paragraph pass ──► seamless re-render, cross-faded in
```

捕捉范围比透镜更大（“过扫描”）。静止时，每边的余量约为透镜的 30%；内容或透镜移动时扩大到约 40%，并偏向移动的方向。透镜在捕捉区域内可自由移动，只有接近边缘时才会重新居中捕捉范围，此时只读取新露出的条带。未变化的文字会在多轮处理之间沿用已擦除的背景，内容移动期间算出的结果会平移复用而不是丢弃，翻译队列也总是优先处理可见的内容。

滚动会被追踪两次。触控板和滚轮输入会在下一帧到来之前就让译文随页面移动；每一帧捕捉到后，再按列测量、精确到亚像素的偏移量，将译文校准到准确位置，因此固定的侧边栏或消息输入框不会带着聊天内容一起移动。只读取滚动进入视野的那一条。

擦除时，纯色和渐变背景用周围的颜色填充；在纹理背景（插画、游戏画面）上，则由设备端的图像修复模型重建背景，译文也会以匹配的粗细和大小排版。

上方的动图是真实 App 在一个虚构聊天页面（`demo/chat.html?lang=ja`）上的效果，使用真实的鼠标和触控板滚动录制；拍摄清单见 `docs/HERO.md`。

这个名字来自韩语：*mwoyeo*（뭐여）是“那是什么？”的方言说法。
